## 分类速查

| 类别 | 错误码 | 是不是「额度用完」 |
| --- | --- | --- |
| Token 频率限额 | `6004` `6000` | ✅ 是 |
| 请求数频率限额 | `6005` `6006` `6007` `6008` `14003` | ✅ 是 |
| 余额耗尽 | `14001` `14002` `14012` `14013` `14014` `14018` | ⚠️ 是，但需充值而非等重置 |
| 活跃会话超限 | `10105` | ❌ 关掉其他会话 |
| 联网搜索额度耗尽 | `15001` | ❌ 关掉联网搜索 |
| 套餐未激活 | `14016` `14017` | ❌ 激活套餐 |
| 排队中 | `6020` `6021` `6022` | ❌ 等待即可 |

## 对限额反推的影响

`build_model_limits()` 只把 **`quota_token_limit` 与 `quota_request_limit`** 视为真正的速率限额样本。
`queue_*` 与 `quota_balance_exhausted` 不参与反推——前者不是限额，后者需要充值而非等窗口重置。
